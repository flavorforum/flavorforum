# Flavour keywords used by fetch_papers.py
#
# A paper is listed if its title or abstract matches at least one line below
# (and at least one author is at an institute in India).
#
# Each line is a Python regular expression. Lines are case-sensitive unless they
# start with (?i). Abstracts on INSPIRE are mostly LaTeX, so "\\to" matches the
# text \to. Lines starting with # are ignored. Edit freely: the next daily run
# uses the new list.
